聯絡 CodeFont

不同問題有各自最快的聯絡管道。我們優先處理重現步驟清晰或注明具體字型名稱的請求。

問題回報與功能建議

最快的方式是使用 GitHub Issues。討論公開、可搜索，並能關聯到修復問題的程式碼。

打開 GitHub Issues

請附上作業系統、VS Code 版本（可在幫助 → 關於中查看）、字型家族名稱，以及預期結果和實際結果。

安全問題

請勿透過公開的 Issue 報告安全問題。

請將問題描述及可提供的重現步驟寄至 hi@codefont.dev。我們將在 3 個工作日內確認收到。

由於擴充功能不傳送任何網路請求，任何對外連接都會按安全問題處理，而非普通異常。

字型作者與隱私請求

如果你擁有字型庫中某款字型的權利，需要更正其名稱、樣本、說明或連結，或希望移除收錄項目，請將字型名稱和頁面網址寄至 hi@codefont.dev。我們會在 7 天內處理。

如需存取、刪除、更正個人資料或諮詢隱私權問題，請以「Data request」為主題寄信至 hi@codefont.dev。我們會在 30 天內回覆。詳見隱私權政策。

其他事宜

媒體、合作與一般諮詢請聯絡 hi@codefont.dev。
