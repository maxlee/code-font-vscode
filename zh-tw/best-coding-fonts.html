程式碼字型安裝和設定指南

按步驟安裝字型，並在 VS Code、JetBrains IDE 或 Sublime Text 中使用。

在 Windows 上安裝

  1. 下載字型檔案（.ttf 或 .otf）。
  2. 以滑鼠右鍵點選字型檔案，選擇「安裝」。
  3. 在編輯器中設定字型家族。

在 macOS 上安裝

  1. 下載字型檔案。
  2. 按兩下字型檔案，再點選「安裝字型」。
  3. 在編輯器設定中選擇字型。

在 Linux 上安裝

在終端機中執行以下指令安裝字型。

# 複製到個人字型資料夾
mkdir -p ~/.local/share/fonts
cp font-file.ttf ~/.local/share/fonts/
# 也可為所有使用者安裝
sudo cp font-file.ttf /usr/share/fonts/
# 更新字型快取
fc-cache -fv

設定 VS Code

在 settings.json 中加入以下設定。

{ "editor.fontFamily": "'Fira Code', 'JetBrains Mono', monospace", "editor.fontLigatures": true, "editor.fontSize": 14, "editor.lineHeight": 22 }

設定 JetBrains IDE

  1. 開啟「檔案 → 設定 → 編輯器 → 字型」。
  2. 選擇字型家族和字級。
  3. 啟用字型連字。

設定 Sublime Text

在使用者設定中加入以下內容。

{ "font_face": "Fira Code", "font_size": 14, "font_options": ["gray_antialias"] }

使用 CodeFont 擴充功能在 VS Code 中輕鬆切換字型

安裝字型後，使用 CodeFont 即可在這 95 款字型中一鍵切換，在 VS Code 中分別管理編輯器與終端機設定，不必手動編輯設定檔。
