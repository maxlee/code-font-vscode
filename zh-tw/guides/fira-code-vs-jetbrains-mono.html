Fira Code 與 JetBrains Mono 該怎麼選

用同一行 JavaScript 比較 Fira Code 與 JetBrains Mono 的程式連字，再以平常的字級觀察小寫字母，挑出讀程式碼時看得最清楚的字型。

先比較常用的運算子

分別開啟下方兩款字型的預覽，貼上範例，統一字級並開啟連字。看看箭頭、小於等於和不等於各是什麼形狀。遮住運算式的兩端，試試能不能一眼認出每個運算子。

const limit = (n) => n <= 10 && n !== 0;
if (limit(1)) console.log("Il1", "O0");

關閉連字再看字母

在兩個預覽中關閉連字。JetBrains Mono 的小寫字母較高，可以特別觀察 console 裡 e 的內部空間。再用慣用的編輯器佈景讀一次。如果喜歡字母造型，也習慣逐一辨認符號，可以保留字型並關閉 editor.fontLigatures。
