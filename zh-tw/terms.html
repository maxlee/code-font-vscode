1. 協議與範圍

本條款適用於你對 codefont.dev 網站（「網站」）以及由發布者 codefont 透過 Visual Studio Marketplace 分發的 Visual Studio Code 擴充功能 CodeFont（「擴充功能」）的使用。使用網站或安裝擴充功能即表示你同意本條款。

CodeFont 是一款免費擴充功能，可將已安裝的等寬字型套用至編輯器和終端機，並將偏好保存到 VS Code 設定中。擴充功能沒有帳戶系統，不傳送網路請求。網站提供文件、字型庫和擴充功能市集連結，不代管或分發字型檔案。

4. 擴充功能會更改哪些設定

實際使用中，請優先瞭解本節。

擴充功能會寫入 VS Code 的 editor.*（例如 editor.fontFamily）、terminal.integrated.* 和 codefont.* 設定。這些更改可能套用至全域、工作區或資料夾。

擴充功能提供重設為預設值（Reset to Default）命令，但不會自動備份此前的設定。請先檢查更改再使用。如果設定複雜或多人共用，請自行備份 settings.json。工作區設定可能覆蓋全域設定。
