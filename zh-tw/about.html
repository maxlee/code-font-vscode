CodeFont 是什麼

CodeFont 是一款 Visual Studio Code 擴充功能，可尋找電腦中已安裝的等寬字型，檢查它們是否適合顯示程式碼，並將你選取的字型套用至編輯器或終端機，無需手動修改 settings.json。

此擴充功能免費使用，採用 MIT 授權條款，完全在你的電腦上執行。

工作原理

在 VS Code 中更換程式設計字型，通常要先確認字型是否已安裝，找出正確的字型家族名稱，修改 settings.json，還得另外設定終端機。CodeFont 把這些操作集中在一個面板中，自動寫入相應設定。

只有通過實際檢查的字型才會列出，判斷依據不只是字型中繼資料。

  • 字型須覆蓋 95 個可列印 ASCII 字元中的至少 76 個。
  • 字母和數字的字元前進寬度須屬於同一組，這樣才能保持程式碼列對齊。
  • 圖示字型、符號字型和非等寬字型會被排除。

擴充功能還會讀取 .ttc 和 .otc 字型集合內的每個字面，辨識透過符號連結指向的字型目錄，並快取結果 24 小時。再次掃描時只檢查有變化的資料夾。

功能範圍

  • 無需帳戶，無遙測或網路請求。無需註冊，資料始終留在你的裝置上。原始碼已公開。
  • 不提供字型下載或銷售。擴充功能僅使用你已安裝的字型，不收取傭金。
  • 不編輯字型或更改主題。擴充功能不會修改字型檔案、顏色或語法醒目提示。
  • 不展示評分或使用者評價。安裝後即可自行核對這裡介紹的行為。
  • 無隱藏設定。擴充功能透過 VS Code 的設定系統寫入標準的 editor.* 和 terminal.integrated.* 設定項目。你後來設定的值優先。

開發與維護

CodeFont 由一名獨立開發者開發和維護。0.1.0 版專注於把字型選擇這一件事做好。

系統要求：Windows、macOS 或 Linux，VS Code 1.100 或更高版本。
