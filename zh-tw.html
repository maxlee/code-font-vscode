管理 VS Code 編輯器與終端機的程式字型

CodeFont 掃描已安裝的字型，驗證哪些適合寫程式，再將你選擇的字型套用至編輯器或終端機。不必手動編輯 JSON，也不蒐集遙測資料。

從擴充功能市集安裝瀏覽字型目錄

每款字型都經過驗證，才會出現在清單裡。

從尋找字型到調整排版

CodeFont 會驗證本機字型，儲存你喜愛的字型，並為編輯器或終端機寫入相應設定。

驗證等寬字型

列出字型前先檢查可列印 ASCII 字元的覆蓋範圍和字元寬度，篩除圖示字型、符號字型和非等寬字型。

字型瀏覽器

在同一清單中查看我的最愛、已安裝和推薦的字型。目前使用的字型旁會顯示勾選記號。

編輯器字型設定

在同一面板中設定字型家族、字級、字重、行高、字距和備用字型模式，不必編輯 settings.json。

終端機字型設定

可以單獨設定整合式終端機，也可以選擇繼承編輯器字型。設定會寫入 terminal.integrated.*。

狀態列與命令

狀態列顯示目前字型和字級，點選即可切換字型。也可以從命令面板重新掃描、重設設定或調整字級。

快速本機掃描

讀取 .ttc 和 .otc 集合中的全部字型，辨識符號連結目錄，快取 24 小時，僅重新掃描有變更的資料夾。全程在本機執行，不蒐集遙測資料。

三步開始使用

安裝 CodeFont 後，可直接在面板中調整字型設定，不必編輯設定檔。

1

安裝 CodeFont

從 VS Code 擴充功能市集安裝。支援 Windows、macOS 和 Linux，需要 VS Code 1.100 或更高版本。

2

開啟 CodeFont 面板

點選活動列中的 CodeFont 圖示，字型瀏覽器會列出我的最愛、已安裝和推薦的字型。

3

套用並調整字型

點選字型即可套用。在編輯器或終端機字型設定中調整字級、字重、行高和字距。

CodeFont 0.1.0 的實際表現

這些行為都可以在擴充功能中親自驗證。

先驗證，再列出

在 95 個可列印 ASCII 字元中，字型須至少覆蓋 76 個，且字母和數字的字寬須屬於同一組。僅在無法量測時才參考中繼資料。

編輯器和終端機可分別設定

更改會寫入全域 editor.* 和 terminal.integrated.* 設定。終端機可以繼承編輯器字型，兩者也可以分別重設。

支援字型集合和連結目錄

支援 .ttc 和 .otc 集合中的所有字型和透過符號連結存取的資料夾。快取保留 24 小時，僅重新掃描有變更的資料夾。
