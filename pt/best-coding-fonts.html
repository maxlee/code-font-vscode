Instalação no Windows

  1. Baixe o arquivo da fonte (.ttf ou .otf).
  2. Clique com o botão direito do mouse no arquivo e escolha “Instalar”.
  3. Defina a família da fonte no editor.

Instalação no macOS

  1. Baixe o arquivo da fonte.
  2. Clique duas vezes no arquivo e escolha “Instalar”.
  3. Selecione a fonte nas configurações do editor.

Instalação no Linux

Instale a fonte a partir da linha de comandos.

# Copiar para a pasta pessoal de fontes
mkdir -p ~/.local/share/fonts
cp font-file.ttf ~/.local/share/fonts/
# Ou instalar para todos os usuários
sudo cp font-file.ttf /usr/share/fonts/
# Atualizar a cache de fontes
fc-cache -fv

Configuração do VS Code

Adicione estas configurações ao settings.json.

{ "editor.fontFamily": "'Fira Code', 'JetBrains Mono', monospace", "editor.fontLigatures": true, "editor.fontSize": 14, "editor.lineHeight": 22 }

Configuração de IDEs da JetBrains

  1. Abra Arquivo → Configurações → Editor → Fonte.
  2. Escolha a família e o tamanho.
  3. Ative as ligaduras da fonte.

Configuração do Sublime Text

Adicione estas opções às suas configurações de usuário.

{ "font_face": "Fira Code", "font_size": 14, "font_options": ["gray_antialias"] }
