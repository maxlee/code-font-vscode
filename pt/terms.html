O CodeFont é uma extensão gratuita que aplica fontes monoespaçadas instaladas ao editor e ao terminal e salva preferências nas configurações do VS Code. Não tem sistema de contas nem faz requisições de rede. O Site fornece documentação, uma galeria de fontes e links para o Marketplace. Não hospeda nem distribui arquivos de fontes.

4. O que a Extensão altera

Na prática, esta é a seção que merece mais atenção.

A Extensão grava configurações do VS Code em editor.* (por exemplo, editor.fontFamily), terminal.integrated.* e codefont.*. As alterações podem valer para todo o aplicativo, para o espaço de trabalho ou para a pasta.

O comando Restaurar os padrões (Reset to Default) está disponível, mas a configuração anterior não tem backup automático. Revise as alterações antes de depender delas, faça uma cópia de settings.json se sua configuração for complexa ou compartilhada e lembre que os ajustes do espaço de trabalho podem prevalecer sobre os globais.
