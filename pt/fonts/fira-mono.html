Usar Fira Mono no VS Code

Cole este trecho nas configurações para usar Fira Mono no editor. As fontes alternativas são as mesmas que o CodeFont configura.

{
  "editor.fontFamily": "'Fira Mono', 'JetBrains Mono', 'SF Mono', Monaco, 'Cascadia Code', 'Roboto Mono', monospace"
}

Sobre a fonte de programação Fira Mono

A companheira da Fira Code sem ligaduras. Uso gratuito. Consulte os termos de licença na fonte oficial. Sem ligaduras de programação.

Hospedada no Google Fonts e carregada automaticamente na amostra. Integra o catálogo CodeFont de 95 famílias.

Perguntas frequentes sobre Fira Mono

Fira Mono é gratuita?

Uso gratuito. Consulte os termos de licença na fonte oficial.

Fira Mono oferece ligaduras?

Não. Sequências como -> e != são desenhadas como caracteres separados.
