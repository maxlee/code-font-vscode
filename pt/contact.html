Contato com o CodeFont

Encontre o canal mais rápido para relatar falhas, comunicar problemas de segurança, corrigir fichas de fontes ou fazer pedidos de privacidade.

Segurança: confirmação em até 3 dias úteis · Privacidade: resposta em até 30 dias

Cada tipo de solicitação tem um canal mais rápido. Priorizamos relatos com passos claros para reproduzir o problema ou com o nome exato da fonte.

Relatos de falhas e pedidos de recursos

O caminho mais rápido é o GitHub Issues. A conversa fica pública, pode ser encontrada por busca e se conecta ao código que resolve o problema.

Abrir o GitHub Issues

Informe seu sistema operacional, a versão do VS Code (Ajuda → Sobre), o nome da família da fonte, o que você esperava e o que aconteceu.

Problemas de segurança

Não abra uma issue pública para comunicar problemas de segurança.

Envie uma descrição para hi@codefont.dev e, se possível, os passos para reproduzir o problema. Confirmaremos o recebimento em até 3 dias úteis.

Como a extensão faz zero requisições de rede, qualquer conexão de saída é tratada como problema de segurança, e não como falha comum.

Autores de fontes e pedidos de privacidade

Se você detém os direitos sobre uma fonte da galeria e quer corrigir o nome, a amostra, a descrição ou o link, ou retirar a ficha, envie o nome da fonte e a URL da página para hi@codefont.dev. Tomamos as providências em até 7 dias.

Para solicitar acesso, exclusão ou correção de dados, ou fazer perguntas sobre privacidade, escreva para hi@codefont.dev com o assunto “Data request”. Respondemos em até 30 dias. Consulte a Política de Privacidade.

Outros assuntos

Imprensa, parcerias ou perguntas gerais: hi@codefont.dev.
