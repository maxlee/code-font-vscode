Teste de legibilidade de fontes com 0/O e 1/l/I

Teste se é fácil distinguir zero, O maiúsculo, um, l minúsculo e I maiúsculo em um identificador real, usando o tamanho de fonte do seu dia a dia.

Guias de instalação e configuração
  • Fira Code ou JetBrains Mono para ler código?
  • Cascadia Code ou Cascadia Mono para código e logs?
  • Como mudar a fonte do terminal integrado do VS Code
  • A fonte do editor não muda no VS Code?

Transcreva sem aumentar o zoom

Cole as duas linhas abaixo em cada amostra. Cubra a primeira linha e digite a segunda olhando para ela. Confira caractere por caractere. Observe o ponto ou o traço no zero e a curva na base do l minúsculo.

O0O0   l1Il   rn m
order_O0 = item_l1 + item_I1

Confira em uma linha de log

Use o tema habitual do editor e repita com uma linha de log ou de dados de teste. Compare rn com m e conte os traços verticais adjacentes. Abra uma alteração extensa com a fonte que permitiu transcrever o identificador real com precisão.
