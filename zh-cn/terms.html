1. 协议与范围

本条款适用于你对 codefont.dev 网站（「网站」）以及由发布者 codefont 通过 Visual Studio Marketplace 分发的 Visual Studio Code 扩展 CodeFont（「扩展」）的使用。使用网站或安装扩展即表示你同意本条款。

CodeFont 是一款免费扩展，可将已安装的等宽字体应用到编辑器和终端，并将偏好保存到 VS Code 设置中。扩展没有账户系统，不发送网络请求。网站提供文档、字体库和扩展市场链接，不托管或分发字体文件。

如果你从 GitHub 获取源代码并自行构建，该代码受 MIT 许可证约束，本条款不适用于该代码。详见第 2 节。

本条款适用于你对网站、以我们的扩展市场发布者身份分发的扩展，以及 CodeFont 名称和标志的使用（见第 7 节）。

4. 扩展会更改哪些设置

实际使用中，请优先了解本节。

扩展会写入 VS Code 的 editor.*（例如 editor.fontFamily）、terminal.integrated.* 和 codefont.* 设置。这些更改可能应用于全局、工作区或文件夹。

扩展提供重置为默认值（Reset to Default）命令，但不会自动备份此前的配置。请先检查更改再使用。如果配置复杂或多人共用，请自行备份 settings.json。工作区设置可能覆盖全局设置。

5. 第三方服务与广告

扩展市场、GitHub 与字体

扩展通过 Visual Studio Marketplace 分发，源代码托管在 GitHub，使用这些平台须遵守其条款。字体库中的字体归各自创作者所有，并按各自的许可证分发。我们展示名称、样张和链接以供识别，不分发字体二进制文件，也不授予字体许可。字体作者可按第 8 节申请更正或移除条目。

广告与链接

启用广告时，网站展示 Google AdSense 投放的广告。我们不选择、控制或认可广告中的产品和服务，与广告主亦无任何关系。你与广告的互动及任何购买均发生在你与广告主之间。广告适用 Google 的条款和隐私政策。Cookie 相关信息请参阅隐私政策。我们不对网站链接的外部资源负责。
