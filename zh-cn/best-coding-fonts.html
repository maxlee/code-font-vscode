在 Windows 上安装

  1. 下载字体文件（.ttf 或 .otf）。
  2. 右键点击字体文件，选择「安装」。
  3. 在编辑器中设置字体族。

在 macOS 上安装

  1. 下载字体文件。
  2. 双击字体文件，再点击「安装字体」。
  3. 在编辑器设置中选择字体。

在 Linux 上安装

在终端中运行以下命令安装字体。

# 复制到个人字体目录
mkdir -p ~/.local/share/fonts
cp font-file.ttf ~/.local/share/fonts/
# 也可为所有用户安装
sudo cp font-file.ttf /usr/share/fonts/
# 刷新字体缓存
fc-cache -fv

配置 VS Code

在 settings.json 中添加以下设置。

{ "editor.fontFamily": "'Fira Code', 'JetBrains Mono', monospace", "editor.fontLigatures": true, "editor.fontSize": 14, "editor.lineHeight": 22 }

配置 JetBrains IDE

  1. 打开「文件 → 设置 → 编辑器 → 字体」。
  2. 选择字体族和字号。
  3. 启用字体连字。

配置 Sublime Text

在用户设置中添加以下内容。

{ "font_face": "Fira Code", "font_size": 14, "font_options": ["gray_antialias"] }

使用 CodeFont 扩展在 VS Code 中轻松切换字体

安装字体后，使用 CodeFont 即可在这 95 款字体中一键切换，在 VS Code 中分别管理编辑器与终端设置，无需手动编辑配置文件。
