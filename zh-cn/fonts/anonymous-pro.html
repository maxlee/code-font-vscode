在 VS Code 中使用 Anonymous Pro

将以下内容粘贴到设置中，即可在编辑器使用 Anonymous Pro。备用字体与 CodeFont 写入的设置一致。

{
  "editor.fontFamily": "'Anonymous Pro', 'JetBrains Mono', 'SF Mono', Monaco, 'Cascadia Code', 'Roboto Mono', monospace"
}
