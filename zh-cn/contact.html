不同问题有各自最快的联系渠道。我们优先处理复现步骤清晰或注明具体字体名称的请求。

问题报告与功能建议

最快的方式是使用 GitHub Issues。讨论公开、可搜索，并能关联到修复问题的代码。

打开 GitHub Issues

请附上操作系统、VS Code 版本（可在帮助 → 关于中查看）、字体族名称，以及预期结果和实际结果。

安全问题

请勿通过公开的 Issue 报告安全问题。

请将问题描述及可提供的复现步骤发至 hi@codefont.dev。我们将在 3 个工作日内确认收到。

由于扩展不发送任何网络请求，任何对外连接都会按安全问题处理，而非普通故障。

字体作者与隐私请求

如果你拥有字体库中某款字体的权利，需要更正其名称、样张、说明或链接，或希望移除条目，请将字体名称和页面网址发至 hi@codefont.dev。我们会在 7 天内处理。

如需访问、删除、更正个人数据或咨询隐私问题，请以「Data request」为主题发邮件至 hi@codefont.dev。我们会在 30 天内答复。详见隐私政策。

其他事宜

媒体、合作及一般咨询请联系 hi@codefont.dev。

CodeFont

CodeFont 是一款在本机运行的 VS Code 扩展，可查找、验证等宽编程字体，并将其应用到编辑器和终端。
