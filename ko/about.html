CodeFont란

CodeFont는 컴퓨터에 설치된 고정폭 글꼴을 찾아 코드 표시에 적합한지 검사하는 Visual Studio Code 확장입니다. settings.json을 직접 수정하지 않고도 선택한 글꼴을 편집기나 터미널에 적용할 수 있습니다.

무료로 사용할 수 있으며 MIT 라이선스에 따라 배포됩니다. 모든 처리는 내 컴퓨터에서 이루어집니다.

작동 방식

VS Code에서 코딩 글꼴을 바꾸려면 보통 설치 여부를 확인하고 정확한 글꼴 패밀리 이름을 찾아 settings.json을 수정한 뒤 터미널도 별도로 설정해야 합니다. CodeFont는 이 과정을 한 패널에 모아 필요한 설정을 대신 기록합니다.

메타데이터만 보고 추정하지 않고 실제 검사에 통과한 글꼴만 표시합니다.

  • 인쇄 가능한 ASCII 문자 95개 중 76개 이상을 지원해야 합니다.
  • 문자와 숫자의 글자 진행 폭이 하나의 그룹에 속해야 합니다. 그래야 코드의 열이 고르게 정렬됩니다.
  • 아이콘 글꼴, 기호 글꼴, 가변폭 글꼴은 제외합니다.

.ttc 및 .otc 모음 안의 모든 서체를 읽고 심볼릭 링크로 연결된 글꼴 폴더도 탐색합니다. 결과는 24시간 동안 캐시하며 변경된 폴더만 다시 검사합니다.

제공하지 않는 기능

  • 계정, 원격 측정, 네트워크 요청이 없습니다. 가입할 필요가 없고 데이터는 기기를 벗어나지 않습니다. 소스 코드는 공개되어 있습니다.
  • 글꼴을 내려받거나 판매하지 않습니다. 이미 설치된 글꼴을 사용하며 수수료를 받지 않습니다.
  • 글꼴을 편집하거나 테마를 바꾸지 않습니다. 글꼴 파일, 색상, 구문 강조를 수정하지 않습니다.
  • 평점이나 추천 후기는 싣지 않습니다. 설치 후 여기에 설명한 동작을 직접 확인할 수 있습니다.
  • 숨겨진 구성이 없습니다. VS Code 설정 시스템의 표준 editor.* 및 terminal.integrated.* 항목에 기록합니다. 나중에 사용자가 지정한 설정이 우선합니다.

개발 및 유지보수

CodeFont는 독립 개발자가 개발하고 관리합니다. 0.1.0 버전은 글꼴 선택이라는 한 가지 작업을 정확하게 처리하는 데 집중합니다.

요구 사항: Windows, macOS 또는 Linux에서 VS Code 1.100 이상.
