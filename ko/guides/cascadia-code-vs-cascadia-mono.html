Cascadia Code와 Cascadia Mono의 차이

같은 기호가 어떻게 보이는지 확인하기

공식 Cascadia 배포 페이지에서 두 글꼴을 설치하고 같은 크기로 예제를 보세요. 합자를 켜면 Cascadia Code는 일부 연산자 기호를 이어서 그립니다. Cascadia Mono는 각 문자를 따로 표시합니다. 식을 일반 텍스트에 붙여 넣어 원래 문자열도 확인해 보세요.
