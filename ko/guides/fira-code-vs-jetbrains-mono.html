자주 쓰는 연산자 비교하기

아래에서 두 글꼴의 미리보기를 열고 예제를 붙여 넣으세요. 크기를 맞추고 합자를 켠 뒤 화살표와 두 비교 연산자를 살펴보세요. 앞뒤를 가렸을 때도 각 연산자가 무엇인지 바로 알 수 있는지 확인하세요.

const limit = (n) => n <= 10 && n !== 0;
if (limit(1)) console.log("Il1", "O0");

합자를 끄고 글자 살펴보기

양쪽에서 합자를 끄세요. JetBrains Mono는 소문자 높이가 큰 편입니다. console의 e 안쪽 공간을 보고 평소 편집기 테마에서도 읽어 보세요. 글자 모양이 마음에 들고 기호는 따로 읽고 싶다면 editor.fontLigatures를 끈 채 사용하면 됩니다.
