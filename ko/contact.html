CodeFont 문의

버그 보고, 보안 문제 제보, 글꼴 등록 정보 정정 및 개인정보 관련 요청에 맞는 창구를 안내합니다.

보안 제보 접수 확인은 영업일 기준 3일 이내 · 개인정보 관련 답변은 30일 이내

문의 유형에 맞는 창구를 이용하면 빠르게 답변받을 수 있습니다. 재현 절차나 글꼴 이름이 명확한 요청을 우선 처리합니다.

버그 보고 및 기능 제안

가장 빠른 창구는 GitHub Issues입니다. 논의 내용을 공개하고 검색할 수 있으며, 문제를 해결한 코드와 연결할 수 있습니다.

GitHub Issues 열기

운영체제, VS Code 버전(도움말 → 정보), 글꼴 패밀리 이름, 예상한 결과와 실제로 일어난 일을 알려 주세요.

보안 문제

보안 문제는 공개 이슈로 등록하지 마세요.

문제 설명과 가능한 경우 재현 절차를 hi@codefont.dev으로 보내 주세요. 영업일 기준 3일 이내에 접수 사실을 알립니다.

확장은 네트워크 요청을 전혀 보내지 않으므로 외부 연결이 발견되면 일반 버그가 아닌 보안 문제로 취급합니다.

글꼴 제작자 및 개인정보 관련 요청

갤러리에 실린 글꼴의 권리자로서 이름, 견본, 설명이나 링크를 바로잡거나 등록을 삭제하려면 글꼴 이름과 페이지 주소를 hi@codefont.dev으로 보내 주세요. 7일 이내에 처리합니다.

개인정보 열람·삭제·정정 요청 또는 개인정보 문의는 제목을 “Data request”로 하여 hi@codefont.dev으로 보내 주세요. 30일 이내에 답변합니다. 자세한 내용은 개인정보 처리방침을 참고하세요.

기타 문의

언론, 제휴 및 일반 문의는 hi@codefont.dev으로 보내 주세요.
