추천 코딩 글꼴

VS Code와 JetBrains IDE에서 사용할 수 있는 코딩 글꼴 95종을 엄선했습니다. Fira Code와 JetBrains Mono 같은 고전부터 Monaspace, Geist Mono, Google Sans Code까지, 무료 또는 시스템 제공 글꼴 80종과 유료 글꼴 15종을 담았습니다. 그중 25종은 프로그래밍 합자를 지원합니다.

글꼴 설치 및 설정 가이드

글꼴을 설치한 다음 VS Code, JetBrains IDE, Sublime Text에서 설정하는 방법을 알아보세요.

  • Fira Code와 JetBrains Mono 코드 가독성 비교
  • Cascadia Code와 Cascadia Mono의 차이
  • VS Code 통합 터미널 글꼴만 바꾸는 방법
  • VS Code 편집기 글꼴 변경이 적용되지 않을 때
  • 0/O와 1/l/I로 코딩 글꼴 가독성 테스트하기
  • 코드는 어떤 글꼴로 표시될까?
  • Microsoft Word에서 코드 글꼴 설정하기

Windows에 설치

  1. 글꼴 파일(.ttf 또는 .otf)을 다운로드합니다.
  2. 파일을 마우스 오른쪽 단추로 클릭하고 ‘설치’를 선택합니다.
  3. 편집기에서 글꼴 모음을 설정합니다.

macOS에 설치

  1. 글꼴 파일을 다운로드합니다.
  2. 파일을 두 번 클릭하고 ‘설치’를 선택합니다.
  3. 편집기 설정에서 글꼴을 선택합니다.

Linux에 설치

터미널에서 다음 명령으로 글꼴을 설치하세요.

# 개인 글꼴 디렉터리에 복사
mkdir -p ~/.local/share/fonts
cp font-file.ttf ~/.local/share/fonts/
# 또는 모든 사용자를 위해 설치
sudo cp font-file.ttf /usr/share/fonts/
# 글꼴 캐시 갱신
fc-cache -fv

VS Code 설정

settings.json에 다음 설정을 추가하세요.

{ "editor.fontFamily": "'Fira Code', 'JetBrains Mono', monospace", "editor.fontLigatures": true, "editor.fontSize": 14, "editor.lineHeight": 22 }

JetBrains IDE 설정

  1. 파일 → 설정 → 편집기 → 글꼴로 이동합니다.
  2. 글꼴 모음과 크기를 선택합니다.
  3. 글꼴 합자를 활성화합니다.

Sublime Text 설정

사용자 설정에 다음 내용을 추가하세요.

{ "font_face": "Fira Code", "font_size": 14, "font_options": ["gray_antialias"] }

CodeFont 확장으로 VS Code 글꼴 바꾸기

글꼴을 설치하면 한 번의 클릭으로 95종 중 원하는 글꼴을 적용할 수 있습니다. 구성 파일을 직접 편집하지 않아도 VS Code 안에서 편집기와 터미널의 글꼴을 관리할 수 있습니다.

확장 설치
클릭하여 적용
글꼴 탐색기에서 선택하면 CodeFont가 설정을 저장합니다.
즐겨찾기
자주 쓰는 글꼴을 고정하세요. 다시 시작해도 즐겨찾기는 유지됩니다.
편집기와 터미널
editor.*와 terminal.integrated.*를 따로 설정합니다.
필요할 때 재검색
캐시를 24시간 보관합니다. 모든 글꼴이나 변경된 폴더만 다시 검색할 수 있습니다.
