4. What the Extension changes

This section matters more than any other, practically speaking.

The Extension writes to VS Code settings under editor.* (for example editor.fontFamily), terminal.integrated.*, and codefont.*. Changes may be written at global, workspace, or folder scope.

It provides a Reset to Default command but does not automatically back up your previous configuration. Review changes before relying on them, keep your own backup of settings.json if your configuration is complex or shared, and remember that workspace settings can override global ones.
