Présentation

CodeFont est une extension pour Visual Studio Code qui repère les polices à chasse fixe déjà installées sur votre ordinateur, vérifie qu’elles conviennent au code et applique celle de votre choix à l’éditeur ou au terminal, sans modification manuelle de settings.json.

L’extension est gratuite, distribuée sous licence MIT et fonctionne entièrement sur votre ordinateur.

Fonctionnement

Changer la police de VS Code suppose souvent de vérifier son installation, de trouver son nom de famille exact, de modifier settings.json et de régler le terminal séparément. CodeFont regroupe ces opérations dans un panneau et renseigne les bons paramètres.

Seules les polices qui passent les contrôles suivants figurent dans la liste. Les métadonnées seules ne suffisent pas.

  • La police couvre au moins 76 des 95 caractères ASCII imprimables.
  • Les lettres et les chiffres présentent un seul groupe de largeurs d’avance, ce qui assure l’alignement du code en colonnes.
  • Les polices d’icônes, de symboles et les polices proportionnelles sont écartées.

L’extension lit aussi chaque variante des collections .ttc et .otc, suit les liens symboliques vers les dossiers de polices, conserve les résultats en cache pendant 24 heures et ne réanalyse que les dossiers modifiés.

Limites de l’extension

  • Aucun compte, aucune télémétrie ni requête réseau. Aucune inscription n’est nécessaire et aucune donnée ne quitte votre appareil. Le code source est public.
  • Aucun téléchargement ni vente de polices. L’extension utilise les polices déjà installées et ne perçoit aucune commission.
  • Aucune modification des polices ou du thème. Les fichiers de police, les couleurs et la coloration syntaxique restent intacts.
  • Ni notes ni témoignages. Vous pouvez vérifier le fonctionnement décrit ici dès l’installation.
  • Aucune configuration cachée. L’extension utilise le système de configuration de VS Code pour écrire dans les paramètres standard editor.* et terminal.integrated.*. Vos réglages ultérieurs restent prioritaires.

Développement et maintenance

CodeFont est développé et maintenu par un développeur indépendant. La version 0.1.0 se concentre sur une seule tâche afin de l’accomplir correctement.

Configuration requise : VS Code 1.100 ou version ultérieure, sous Windows, macOS ou Linux.
