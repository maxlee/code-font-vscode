Guides d’installation et de configuration

Suivez les étapes pour installer vos polices et les configurer dans VS Code, les IDE JetBrains ou Sublime Text.

Installation sous Windows

  1. Téléchargez le fichier de police (.ttf ou .otf).
  2. Faites un clic droit sur le fichier et choisissez « Installer ».
  3. Choisissez la famille dans votre éditeur.

Installation sous macOS

  1. Téléchargez le fichier de police.
  2. Double-cliquez sur le fichier puis cliquez sur « Installer ».
  3. Sélectionnez la police dans les réglages de votre éditeur.

Installation sous Linux

Installez la police en ligne de commande.

# Copier dans le dossier personnel des polices
mkdir -p ~/.local/share/fonts
cp font-file.ttf ~/.local/share/fonts/
# Ou installer pour tous les utilisateurs
sudo cp font-file.ttf /usr/share/fonts/
# Mettre à jour le cache des polices
fc-cache -fv

Configuration de VS Code

Ajoutez ces réglages à votre fichier settings.json.

{ "editor.fontFamily": "'Fira Code', 'JetBrains Mono', monospace", "editor.fontLigatures": true, "editor.fontSize": 14, "editor.lineHeight": 22 }

Configuration des IDE JetBrains

  1. Ouvrez Fichier → Paramètres → Éditeur → Police.
  2. Choisissez une famille et une taille.
  3. Activez les ligatures de police.

Configuration de Sublime Text

Ajoutez ces options à vos préférences utilisateur.

{ "font_face": "Fira Code", "font_size": 14, "font_options": ["gray_antialias"] }

Changez de police dans VS Code avec CodeFont

Une fois installées, ces 95 polices se sélectionnent en un clic. CodeFont gère les réglages de police de l’éditeur et du terminal dans VS Code, sans modification manuelle des fichiers de configuration.
