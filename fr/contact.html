Anomalies et demandes de fonctionnalités

GitHub Issues est le moyen le plus rapide. Les échanges y sont publics, consultables par recherche et reliés au code qui résout le problème.

Ouvrir GitHub Issues

Précisez votre système d’exploitation, la version de VS Code (Aide → À propos), le nom de la famille de polices, le résultat attendu et le résultat obtenu.

Problèmes de sécurité

Merci de ne pas signaler de problème de sécurité dans un ticket public.

Écrivez à hi@codefont.dev en décrivant le problème et, si possible, la manière de le reproduire. Nous accuserons réception dans les 3 jours ouvrés.

L’extension n’émet aucune requête réseau. Toute connexion sortante est donc traitée comme un incident de sécurité plutôt que comme une anomalie ordinaire.

Créateurs de polices et demandes relatives aux données

Si vous détenez les droits sur une police de la galerie et souhaitez corriger son nom, son spécimen, sa description ou son lien, ou faire retirer sa fiche, envoyez le nom de la police et l’URL de la page à hi@codefont.dev. Nous donnons suite sous 7 jours.

Pour accéder à vos données, les supprimer, les rectifier ou poser une question sur leur traitement, écrivez à hi@codefont.dev avec pour objet « Data request ». Nous répondons sous 30 jours. Consultez la politique de confidentialité.
