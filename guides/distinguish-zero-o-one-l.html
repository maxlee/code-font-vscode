Coding font readability test for 0/O and 1/l/I

Test whether a coding font makes zero, capital O, one, lowercase l and capital I easy to distinguish. Use an identifier from your own code at normal reading size.

Font Installation & Setup Guides
  • Fira Code vs JetBrains Mono for reading code
  • Cascadia Code vs Cascadia Mono for code and logs
  • Change the VS Code integrated terminal font
  • VS Code editor font not changing? Check the fallback

Read the sample before zooming in

Paste the two lines below into each font specimen. Use the size you read every day. Cover the first line and type the second from sight, then compare it character by character. A dot or slash in zero can help, as can a foot on lowercase l.

O0O0   l1Il   rn m
order_O0 = item_l1 + item_I1

Check the same shapes in context

Repeat with your editor theme and a line from a log or a test fixture. Look at rn beside m, then at adjacent vertical strokes. Keep the font in which you can transcribe the real identifier reliably. A decorative difference visible only at large sizes will do little for a dense diff.
