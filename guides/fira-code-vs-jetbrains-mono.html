Fira Code vs JetBrains Mono for reading code

Compare Fira Code and JetBrains Mono with the same line of JavaScript. Try their operator ligatures, then check how each handles small letters at your usual zoom.

Compare the operators you actually use

Open both specimens below. Paste the sample into each, match the font size and switch ligatures on. Look at the arrow and the two comparisons. Cover the rest of the line and read each expression aloud. Which symbols can you identify at a glance?

const limit = (n) => n <= 10 && n !== 0;
if (limit(1)) console.log("Il1", "O0");

Judge the letters separately

Turn ligatures off in both tabs. JetBrains Mono has tall lowercase letters; look at the space inside the e in console. Try the same line in your editor with your usual theme. If you like the letters but prefer separate operators, leave editor.fontLigatures off.
