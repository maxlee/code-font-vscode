0/O と 1/l/I で試すコーディングフォントの判読性

ゼロと大文字の O、数字の 1 と小文字の l、大文字の I を区別できますか。普段の文字サイズで識別子を書き写し、似た字形の読みやすさを試します。

フォントのインストールと設定
  • Fira Code と JetBrains Mono の読みやすさを比較
  • Cascadia Code と Cascadia Mono の違い
  • VS Code の統合ターミナルだけフォントを変える
  • VS Code でエディターのフォントが変わらないとき

拡大せずに識別子を書き写す

下の二行をそれぞれのフォント見本に貼り付けます。一行目を隠し、二行目を見ながら手で打ち直して一文字ずつ照合します。ゼロの中央の点や斜線、小文字の l の下端の曲がりに注目します。

O0O0   l1Il   rn m
order_O0 = item_l1 + item_I1

実際のログで確かめる

普段の配色に戻し、ログやテストデータから一行選んで繰り返します。rn と m を隣に並べて読み、縦線が連続した箇所も確かめます。正しく書き写せたフォントで行数の多い差分を開き、実際のサイズでも読み分けられるか確認してください。

  • Intel One Mono の文字見本
  • Atkinson Hyperlegible Mono の文字見本
