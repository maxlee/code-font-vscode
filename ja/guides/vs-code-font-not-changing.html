VS Code でエディターのフォントが変わらないとき

VS Code のフォント設定が反映されないときは、インストール済みのファミリー名とワークスペースの設定を順に確認します。ウェブの見本は独自にフォントを読み込めます。

フォントのインストールと設定
  • Fira Code と JetBrains Mono の読みやすさを比較
  • Cascadia Code と Cascadia Mono の違い
  • VS Code の統合ターミナルだけフォントを変える
  • 0/O と 1/l/I で試すコーディングフォントの判読性

システムでファミリー名を調べる

システムのフォントビューアーで書体を開き、ファミリー名をコピーします。ファイル名には太さやバージョン番号が含まれる場合があります。editor.fontFamily の先頭にファミリー名、末尾に monospace を置きます。例では Source Code Pro がインストール済みであることを前提にしています。

{
  "editor.fontFamily": "'Source Code Pro', monospace"
}

空のウィンドウとプロジェクトを比較する

空のウィンドウと作業中のプロジェクトで同じテキストを開きます。空のほうだけ変わったら、ワークスペース設定で editor.fontFamily を検索し、言語別の設定も確認します。インストール直後に両方とも変わらなければ、VS Code を再起動し、数字のゼロや小文字の l を比べてください。

  • Fira Code の文字見本
  • Source Code Pro の文字見本
