Cascadia Code と Cascadia Mono の違い

Microsoft の Cascadia Code と Cascadia Mono は、演算子の合字の有無が異なります。コードやログの読み方に合わせて、二つの書体を選び分けられます。

演算子がどう表示されるか

Cascadia の公式リリースから両方をインストールし、同じサイズで例文を表示します。合字を有効にすると Cascadia Code では一部の記号がつながり、Cascadia Mono では一文字ずつ表示されます。式をプレーンテキストにコピーし、元の文字列も確かめてください。

x != y    x == y    x => y    x <= y

エディターと端末で使い分ける

普段使う言語の式を Cascadia Code で読み、差分の記号を一文字ずつ数える端末では Cascadia Mono を試します。VS Code でそれぞれのフォントを設定し、同じ差分を開いて読みやすい組み合わせを選びます。
