おすすめの等幅フォント

VS Code や JetBrains IDE で使えるコーディング用フォント 95 種類を厳選しました。定番の Fira Code や JetBrains Mono から Monaspace、Geist Mono、Google Sans Code まで、無料・システム標準が 80 種類、有料が 15 種類。そのうち 25 種類はプログラミング合字に対応します。

2026 年のおすすめフォント

コードの読みやすさ、合字の対応、IDE との相性を基準に選びました。

合字で選ぶ

  • Fira Code — 定番の合字フォント
  • JetBrains Mono — IDE によく馴染む設計
  • Cascadia Code — Microsoft の合字フォント
  • Monaspace — GitHub が 2023 年に公開

読みやすさで選ぶ

  • Source Code Pro — Adobe のプロ向け書体
  • IBM Plex Mono — 多くの言語に対応
  • Inconsolata — 人気のオープンソース書体
  • Geist Mono — Vercel のモダンなデザイン

注目の書体

  • Maple Mono CN — 中国語とコードの混植向け
  • Commit Mono — Git のコミットを読みやすく表示
  • Zenbones Mono — Iosevka をもとにした書体
  • Lilex — 現代的な合字

有料の書体

  • MonoLisa — ゆったりした字幅
  • Dank Mono — 特徴的なイタリック
  • Berkeley Mono — クラシックな商用等幅フォント
  • Pragmata Pro — プロ向けの合字

フォントのインストールと設定

フォントをインストールし、VS Code、JetBrains IDE、Sublime Text で使い始めるまでの手順です。

  • Fira Code と JetBrains Mono の読みやすさを比較
  • Cascadia Code と Cascadia Mono の違い
  • VS Code の統合ターミナルだけフォントを変える
  • VS Code でエディターのフォントが変わらないとき
  • 0/O と 1/l/I で試すコーディングフォントの判読性
  • ソースコードはどのフォントで表示される？
  • Microsoft Word でコードに使うフォント

Windows にインストール

  1. フォントファイル（.ttf または .otf）をダウンロードします。
  2. ファイルを右クリックし「インストール」を選びます。
  3. エディターでフォントファミリーを指定します。

macOS にインストール

  1. フォントファイルをダウンロードします。
  2. ファイルをダブルクリックし「インストール」をクリックします。
  3. エディターの設定でフォントを選びます。

Linux にインストール

ターミナルからフォントをインストールします。

# 個人用のフォントディレクトリにコピー
mkdir -p ~/.local/share/fonts
cp font-file.ttf ~/.local/share/fonts/
# 全ユーザー向けにインストールする場合
sudo cp font-file.ttf /usr/share/fonts/
# フォントキャッシュを更新
fc-cache -fv

VS Code の設定

次の内容を settings.json に追加します。

{ "editor.fontFamily": "'Fira Code', 'JetBrains Mono', monospace", "editor.fontLigatures": true, "editor.fontSize": 14, "editor.lineHeight": 22 }

JetBrains IDE の設定

  1. 「ファイル → 設定 → エディター → フォント」を開きます。
  2. フォントファミリーとサイズを選びます。
  3. 合字を有効にします。

Sublime Text の設定

次の内容をユーザー設定に追加します。

{ "font_face": "Fira Code", "font_size": 14, "font_options": ["gray_antialias"] }

VS Code 拡張機能 CodeFont で書体を切り替える

インストールしたフォントはワンクリックで切り替えられます。この 95 書体を使うときも設定ファイルの手編集は不要。エディターとターミナルの設定を VS Code 内で管理できます。
