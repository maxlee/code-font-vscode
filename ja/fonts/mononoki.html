VS Code で Mononoki を使う

次の設定を貼り付けると、エディターで Mononoki を使用できます。代替フォントは CodeFont と共通です。

{
  "editor.fontFamily": "'Mononoki', 'JetBrains Mono', 'SF Mono', Monaco, 'Cascadia Code', 'Roboto Mono', monospace"
}

プログラミングフォント Mononoki について

軽やかなプログラミングフォント。 無料で利用できます。利用条件は公式の配布元をご確認ください。 コード用の合字はありません。

Mononoki を端末にインストールすると実際の書体で表示できます。未インストールの場合は標準の等幅フォントで表示します。 CodeFont に収録された全95書体のひとつです。

Mononoki のよくある質問

Mononoki は無料ですか？

無料で利用できます。利用条件は公式の配布元をご確認ください。

Mononoki は合字に対応していますか？

いいえ。-> や != のような記号列は個別の文字として表示されます。

Mononoki はどこで入手できますか？

Mononoki は GitHub から入手できます。
