CodeFont へのお問い合わせ

不具合やセキュリティ上の問題の報告、フォント掲載情報の訂正、プライバシーに関するご請求の窓口をご案内します。

セキュリティ報告の受領連絡は 3 営業日以内 · プライバシーに関する回答は 30 日以内

ご用件に応じて以下の窓口をご利用ください。再現手順や該当フォント名が明確なお問い合わせから優先して対応します。

不具合報告と機能のご要望

最も早い窓口は GitHub Issues です。やり取りが公開・検索可能になり、修正したコードと関連付けられます。

GitHub Issues を開く

OS、VS Code のバージョン（ヘルプ → バージョン情報）、フォントのファミリ名、期待した結果と実際の結果をお知らせください。

セキュリティ上の問題

セキュリティ上の問題は公開 Issue に投稿しないでください。

問題の説明と、可能であれば再現手順を hi@codefont.dev までお送りください。3 営業日以内に受領をお知らせします。

拡張機能からのネットワークリクエストは 0 件であるため、外部への通信はすべて、通常の不具合でなくセキュリティ上の問題として扱います。

フォントの作者の方・プライバシーに関するご請求

ギャラリー掲載フォントの権利者で、名称、見本、説明、リンクの訂正や掲載の取り下げをご希望の場合は、フォント名とページの URL を hi@codefont.dev までお送りください。7 日以内に対応します。

個人データの開示、削除、訂正、その他プライバシーに関するご用件は、件名を「Data request」とし、hi@codefont.dev にご連絡ください。30 日以内に回答します。詳しくはプライバシーポリシーをご覧ください。

その他のお問い合わせ

取材、提携、一般のお問い合わせ先は hi@codefont.dev です。
