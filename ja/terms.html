1. 同意と適用範囲

本規約は、codefont.dev のウェブサイト（以下「当サイト」）および発行者 codefont が Visual Studio Marketplace を通じて配布する Visual Studio Code 用 CodeFont 拡張機能（以下「本拡張機能」）の利用に適用されます。当サイトの利用または本拡張機能のインストールにより、本規約に同意したものとします。

CodeFont は、インストール済みの等幅フォントをエディターやターミナルに適用し、設定を VS Code に保存する無料の拡張機能です。アカウント機能やネットワーク通信はありません。当サイトは文書、フォントギャラリー、Marketplace へのリンクを提供しますが、フォントファイルのホスティングや配布は行いません。

GitHub で入手したソースコードをご自身でビルドする場合、そのコードには本規約ではなく MIT ライセンスが適用されます（第 2 節）。

本拡張機能のソースコードは MIT ライセンスで公開されており、その写しは github.com/maxlee/code-font-vscode/blob/main/LICENSE にあります。著作権表示と許諾表示を含めることを条件に、使用、複製、変更、結合、公開、配布、再許諾、および複製物の販売を広く認めています。コードに関して本規約と MIT ライセンスの内容が矛盾する場合、MIT ライセンスが優先します。

本規約は当サイトの利用、当方の Marketplace 発行者名義で配布する本拡張機能の利用、および CodeFont の名称・ロゴの使用に適用されます（第 7 節）。

3. 利用上の禁止事項

利用者は以下の行為を行わないことに同意するものとします。

  • 当サイトを利用してマルウェア、フィッシングコンテンツ、違法な資料を配布すること。
  • 当サイト、ホスティング環境、解析・広告アカウントへの不正アクセスを試みること。
  • 他の利用者へのサービスを低下させる規模でスクレイピングやリクエストを行うこと。
  • 広告のクリックや表示を自動生成するなどの無効な操作を行うこと、または広告配信や測定を妨げること。
  • 本拡張機能を自作と偽ること、必要な著作権表示を削除すること、無断で推奨を受けているかのように示すこと、または改変版を codefont の発行者名義で再配布すること。

広告の無効な操作は Google に報告し、該当するトラフィックを遮断することがあります。

4. 拡張機能が変更する設定

実際の利用に際して、特にご確認いただきたい事項です。

本拡張機能は VS Code の editor.*（例：editor.fontFamily）、terminal.integrated.*、codefont.* の各設定に書き込みます。変更の適用範囲はグローバル、ワークスペース、フォルダーのいずれかです。

既定値に戻す（Reset to Default）コマンドがありますが、以前の設定を自動でバックアップすることはありません。使用前に変更を確認し、設定が複雑な場合や共有している場合はご自身で settings.json をバックアップしてください。ワークスペースの設定がグローバル設定より優先される場合があります。

5. 第三者のサービスと広告

Marketplace、GitHub、フォント

本拡張機能は Visual Studio Marketplace で配布し、ソースコードは GitHub で公開しています。各プラットフォームの規約が適用されます。掲載フォントは各制作者に帰属し、それぞれのライセンスで配布されています。当方は識別のため名称、見本、リンクを掲載しますが、フォントのバイナリを配布せず、いかなるフォントについてもライセンスを付与しません。作者は第 8 節の窓口から訂正・削除を請求できます。

広告とリンク

広告が有効な場合、当サイトは Google AdSense の広告を表示します。当方は広告の商品やサービスを選定、管理、推奨せず、広告主と関係はありません。広告の利用や購入は利用者と広告主との間で行われます。広告には本規約でなく Google の規約とプライバシーポリシーが適用されます。Cookie についてはプライバシーポリシーをご覧ください。当方はリンク先の外部リソースに責任を負いません。
