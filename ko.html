VS Code 편집기와 터미널의 코딩 글꼴 관리

CodeFont가 설치된 글꼴을 검색하고 코딩에 적합한지 확인합니다. 원하는 글꼴을 골라 편집기나 터미널에 적용하세요. JSON을 편집할 필요가 없으며 원격 분석 데이터도 수집하지 않습니다.

Marketplace에서 설치글꼴 목록 보기

목록에 올리기 전에 모든 글꼴을 검증합니다.

글꼴 찾기부터 세부 설정까지

설치된 글꼴을 확인하고 자주 쓰는 글꼴을 즐겨찾기에 보관하세요. CodeFont가 편집기나 터미널에 맞는 설정을 저장합니다.

고정폭 글꼴 검증

목록에 표시하기 전에 출력 가능한 ASCII 문자의 범위와 글자 너비를 확인합니다. 아이콘, 기호 및 가변폭 글꼴은 걸러냅니다.

글꼴 탐색기

즐겨찾기, 설치된 글꼴, 추천 글꼴을 한 트리에서 확인할 수 있습니다. 현재 사용 중인 글꼴에는 확인 표시가 붙습니다.

편집기 글꼴 설정

한 화면에서 글꼴 모음, 크기, 굵기, 줄 높이, 자간, 대체 글꼴 모드를 설정하세요. settings.json을 직접 편집할 필요가 없습니다.

터미널 글꼴 설정

통합 터미널을 개별적으로 설정하거나 편집기 글꼴 상속을 선택하세요. 값은 terminal.integrated.*에 저장됩니다.

상태 표시줄과 명령

상태 표시줄의 현재 글꼴과 크기를 클릭하면 글꼴 선택기가 열립니다. 명령 팔레트에서 글꼴을 다시 검색하거나 설정을 초기화하고 크기를 바꿀 수 있습니다.

빠른 로컬 재검색

.ttc 및 .otc 파일의 모든 서체를 읽고 심볼릭 링크로 연결된 폴더도 검색합니다. 24시간 캐시를 사용해 변경된 폴더만 다시 검색합니다. 모든 작업은 로컬에서 이루어지며 원격 분석은 없습니다.

세 단계로 시작하기

CodeFont를 설치하면 구성 파일을 열지 않고도 글꼴 설정을 바꿀 수 있습니다.

1

CodeFont 설치

VS Code Marketplace에서 설치하세요. VS Code 1.100 이상이 필요하며 Windows, macOS, Linux를 지원합니다.

2

CodeFont 패널 열기

활동 표시줄의 CodeFont 아이콘을 클릭하세요. 글꼴 탐색기에 즐겨찾기, 설치된 글꼴, 추천 글꼴이 표시됩니다.

3

글꼴 적용 및 조정

글꼴을 클릭해 적용하세요. 편집기 또는 터미널 글꼴 설정에서 크기, 굵기, 줄 높이, 자간을 조정할 수 있습니다.

CodeFont 0.1.0의 작동 방식

확장에서 직접 확인할 수 있는 동작입니다.

검증을 마친 글꼴만 표시

출력 가능한 ASCII 문자 95개 중 76개 이상을 포함해야 하며, 영문자와 숫자의 글자 진행 폭이 같은 그룹에 속해야 합니다. 메타데이터는 보조 수단으로만 사용합니다.

편집기와 터미널을 개별 설정

변경 사항은 전역 editor.* 및 terminal.integrated.* 설정에 저장합니다. 터미널은 편집기 글꼴을 상속할 수 있으며 두 설정을 따로 초기화할 수 있습니다.

글꼴 모음과 연결된 폴더 지원

.ttc 및 .otc 모음의 모든 서체를 읽고 심볼릭 링크로 연결된 폴더를 따라갑니다. 결과를 24시간 캐시하고 변경된 폴더만 다시 검색합니다.

편집기와 터미널 글꼴을 한 패널에서 관리하세요

CodeFont 0.1.0은 MIT 라이선스의 무료 확장이며 내 컴퓨터에서만 실행됩니다. 계정이 필요 없고 원격 분석 데이터를 수집하지 않습니다.
