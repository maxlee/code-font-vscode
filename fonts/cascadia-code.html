Use Cascadia Code in VS Code

Paste this into your settings to set Cascadia Code for the editor. The fallbacks are the same ones CodeFont writes.

{
  "editor.fontFamily": "'Cascadia Code', 'JetBrains Mono', 'SF Mono', Monaco, 'Cascadia Code', 'Roboto Mono', monospace",
  "editor.fontLigatures": true
}

About the Cascadia Code coding font

The official font from Microsoft, default in VS Code. Cascadia Code is a free monospace coding font with programming ligatures.

Cascadia Code is not hosted on Google Fonts. The specimen above renders in the real face when the font is installed on your device; if it is not installed, the page falls back to a standard monospace face so the layout stays intact. It is one of the 15 CodeFont Top Picks.

Cascadia Code FAQ

Is Cascadia Code free?

Yes. Cascadia Code is free to use; check the official source for the exact licence terms.

Does Cascadia Code support ligatures?

Yes. Cascadia Code ships programming ligatures. Use the ligature switch above the specimen, or set "editor.fontLigatures": true in VS Code.

Where can I get Cascadia Code?

Cascadia Code is available from GitHub and Microsoft Store. The download links are listed in the Where to get section above.
