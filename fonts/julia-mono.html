Use Julia Mono in VS Code

Paste this into your settings to set Julia Mono for the editor. The fallbacks are the same ones CodeFont writes.

{
  "editor.fontFamily": "'Julia Mono', 'JetBrains Mono', 'SF Mono', Monaco, 'Cascadia Code', 'Roboto Mono', monospace",
  "editor.fontLigatures": true
}

About the Julia Mono coding font

A font designed specifically for the Julia language. Julia Mono is a free monospace coding font with programming ligatures.

Julia Mono is not hosted on Google Fonts. The specimen above renders in the real face when the font is installed on your device; if it is not installed, the page falls back to a standard monospace face so the layout stays intact. It is one of the 95 families in the CodeFont catalog.

Julia Mono FAQ

Is Julia Mono free?

Yes. Julia Mono is free to use; check the official source for the exact licence terms.

Does Julia Mono support ligatures?

Yes. Julia Mono ships programming ligatures. Use the ligature switch above the specimen, or set "editor.fontLigatures": true in VS Code.

Where can I get Julia Mono?

Julia Mono is available from GitHub and Official Website. The download links are listed in the Where to get section above.
