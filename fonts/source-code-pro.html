Use it in VS Code

Paste this into your settings to set Source Code Pro for the editor. The fallbacks are the same ones CodeFont writes.

{
  "editor.fontFamily": "'Source Code Pro', 'JetBrains Mono', 'SF Mono', Monaco, 'Cascadia Code', 'Roboto Mono', monospace"
}
