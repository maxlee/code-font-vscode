About the Comic Shanns coding font

A professional-grade alternative to Comic Sans. Comic Shanns is a paid monospace coding font without programming ligatures.

Comic Shanns is not hosted on Google Fonts. The specimen above renders in the real face when the font is installed on your device; if it is not installed, the page falls back to a standard monospace face so the layout stays intact. It is one of the 95 families in the CodeFont catalog.

Comic Shanns FAQ

Is Comic Shanns free?

No. Comic Shanns is a commercial font, sold by its vendor.

Does Comic Shanns support ligatures?

No. Comic Shanns has no programming ligatures, so sequences such as -> and != are drawn as separate characters.
