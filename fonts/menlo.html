About the Menlo coding font

A system font built into macOS. Menlo is a free monospace coding font without programming ligatures.

Menlo ships with supported operating systems, so there is nothing to download before you try it, and the specimen above renders in the real face on those systems. It is one of the 95 families in the CodeFont catalog.

Menlo FAQ

Is Menlo free?

Yes. Menlo is bundled with supported operating systems, so there is no separate purchase.

Does Menlo support ligatures?

No. Menlo has no programming ligatures, so sequences such as -> and != are drawn as separate characters.

Where can I get Menlo?

Menlo is already on supported systems — there is nothing to download.
