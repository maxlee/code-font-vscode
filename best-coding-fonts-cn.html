编程字体安装和配置指南

详细的字体安装方法和VS Code、JetBrains IDE等主流编辑器配置指南

🪟

Windows 安装

  1. 下载字体文件（.ttf 或 .otf）
  2. 右键点击字体文件，选择"安装"
  3. 在编辑器中设置字体族
🍎

macOS 安装

  1. 下载字体文件
  2. 双击字体文件，点击"安装字体"
  3. 在编辑器设置中选择字体
🐧

Linux 安装

使用命令行安装字体：

# 复制字体到用户字体目录 cp font-file.ttf ~/.fonts/ # 或复制到系统字体目录 sudo cp font-file.ttf /usr/share/fonts/ # 更新字体缓存 fc-cache -fv
⚙️

VS Code 配置

在 settings.json 中添加配置：

{ "editor.fontFamily": "'Fira Code', 'JetBrains Mono', monospace", "editor.fontLigatures": true, "editor.fontSize": 14, "editor.lineHeight": 1.5 }
🔧

JetBrains IDE 配置

  1. File → Settings → Editor → Font
  2. 选择字体族和大小
  3. 启用连字支持
🎨

Sublime Text 配置

在用户设置中添加：

{ "font_face": "Fira Code", "font_size": 14, "font_options": ["gray_antialias"] }
