1. Vereinbarung und Geltungsbereich

Diese Bedingungen regeln die Nutzung der Website codefont.dev (die „Website“) und der CodeFont-Erweiterung für Visual Studio Code (die „Erweiterung“), die über den Visual Studio Marketplace unter dem Herausgebernamen codefont vertrieben wird. Mit der Nutzung der Website oder der Installation der Erweiterung stimmen Sie diesen Bedingungen zu.

CodeFont ist eine kostenlose Erweiterung, die installierte Festbreitenschriften für Editor und Terminal einstellt und Ihre Präferenzen in den VS-Code-Einstellungen speichert. Sie hat kein Kontosystem und stellt keine Netzwerkanfragen. Die Website bietet Dokumentation, eine Schriftgalerie und Links zum Marketplace. Sie hostet oder vertreibt keine Schriftdateien.

Wenn Sie den Quellcode von GitHub beziehen und selbst bauen, gilt für diesen Code die MIT-Lizenz und nicht diese Vereinbarung. Siehe Abschnitt 2.

4. Welche Änderungen die Erweiterung vornimmt

Für den praktischen Einsatz ist dieser Abschnitt besonders wichtig.

Die Erweiterung ändert VS-Code-Einstellungen unter editor.* (z. B. editor.fontFamily), terminal.integrated.* und codefont.*. Änderungen können für den Benutzer, einen Arbeitsbereich oder einen einzelnen Ordner gespeichert werden.

Es steht der Befehl Reset to Default zum Zurücksetzen auf die Standardwerte zur Verfügung. Ihre vorherige Konfiguration wird nicht automatisch gesichert. Prüfen Sie die Änderungen, bevor Sie sich darauf verlassen. Sichern Sie bei komplexen oder gemeinsam genutzten Konfigurationen Ihre settings.json selbst. Einstellungen eines Arbeitsbereichs können globale Einstellungen überschreiben.

Marketplace, GitHub und Schriften

Die Erweiterung wird über den Visual Studio Marketplace vertrieben, der Quellcode wird auf GitHub gehostet. Es gelten die Bedingungen der jeweiligen Plattform. Die Schriften in der Galerie gehören ihren Urhebern und werden unter eigenen Lizenzen vertrieben. Wir zeigen zur Identifizierung Namen, Schriftproben und Links, stellen keine Schriftdateien bereit und erteilen keine Lizenzen an Schriften. Schriftgestalter können über Abschnitt 8 Berichtigungen oder die Entfernung eines Eintrags beantragen.
