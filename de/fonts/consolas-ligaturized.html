Consolas Ligaturized in VS Code verwenden

Füge den Ausschnitt in die Einstellungen ein, um Consolas Ligaturized im Editor zu verwenden. Die Ersatzschriften entsprechen den Vorgaben von CodeFont.

  "editor.fontLigatures": true
}
