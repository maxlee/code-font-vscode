In welcher Schrift wird Code angezeigt?

Editoren zeigen Quellcode meist in einer Schrift mit fester Zeichenbreite an. Dieselbe Python-Datei kann auf einem Bildschirm in Consolas und auf einem anderen in Fira Code erscheinen.

Warum die Spalten bündig bleiben

Vor jedem Gleichheitszeichen im Beispiel stehen drei Buchstaben und ein Leerzeichen. In einer dicktengleichen Schrift sind drei i genauso breit wie drei W. Die Gleichheitszeichen stehen untereinander. Probieren Sie beide Schriftmuster unten in Ihrer üblichen Lesegröße aus.

iii = 100
WWW = 200

Die Schrift im Editor nachschlagen

Suchen Sie in den Einstellungen von VS Code nach editor.fontFamily. Für lateinische Buchstaben wird in der Regel die erste installierte Schrift in der Liste verwendet. Fehlende Zeichen kann eine weitere Schrift liefern. Wechseln Sie die Schrift und betrachten Sie dieselbe Datei erneut.
