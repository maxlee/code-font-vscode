Installation unter Windows

  1. Lade die Schriftdatei (.ttf oder .otf) herunter.
  2. Klicke mit der rechten Maustaste auf die Datei und wähle „Installieren“.
  3. Lege die Schriftfamilie im Editor fest.

Installation unter macOS

  1. Lade die Schriftdatei herunter.
  2. Öffne die Datei per Doppelklick und klicke auf „Installieren“.
  3. Wähle die Schrift in den Editor-Einstellungen.

Installation unter Linux

Installiere die Schrift über die Befehlszeile.

# In den persönlichen Schriftordner kopieren
mkdir -p ~/.local/share/fonts
cp font-file.ttf ~/.local/share/fonts/
# Alternativ für alle Benutzer installieren
sudo cp font-file.ttf /usr/share/fonts/
# Schriftcache aktualisieren
fc-cache -fv

VS Code einrichten

Ergänze die folgenden Werte in deiner settings.json.

{ "editor.fontFamily": "'Fira Code', 'JetBrains Mono', monospace", "editor.fontLigatures": true, "editor.fontSize": 14, "editor.lineHeight": 22 }

JetBrains-IDEs einrichten

  1. Öffne Datei → Einstellungen → Editor → Schriftart.
  2. Wähle Schriftfamilie und Größe.
  3. Aktiviere die Schriftligaturen.

Sublime Text einrichten

Ergänze die folgenden Werte in deinen Benutzereinstellungen.

{ "font_face": "Fira Code", "font_size": 14, "font_options": ["gray_antialias"] }

Mit der CodeFont-Erweiterung Schriften in VS Code wechseln

Sind die Schriften installiert, kannst du mit einem Klick zwischen den 95 Familien wechseln. CodeFont verwaltet die Einstellungen für Editor und Terminal direkt in VS Code. Eine manuelle Änderung der Konfigurationsdateien entfällt.

Erweiterung installieren
Mit einem Klick anwenden
Wähle eine Schrift in der Übersicht. CodeFont trägt die Einstellung ein.
Favoriten
Deine angehefteten Schriften bleiben auch nach dem Neustart erhalten.
Editor und Terminal
Getrennte Einstellungen für editor.* und terminal.integrated.*.
Erneut suchen
Der Cache gilt 24 Stunden. Durchsuche alles oder nur geänderte Ordner.
