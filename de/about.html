Was ist CodeFont?

CodeFont ist eine Erweiterung für Visual Studio Code. Sie findet die auf Ihrem Gerät installierten Festbreitenschriften, prüft ihre Eignung für Code und stellt die gewählte Schrift im Editor oder Terminal ein. Sie müssen dazu settings.json nicht von Hand bearbeiten.

Sie ist kostenlos, steht unter der MIT-Lizenz und läuft vollständig auf Ihrem Computer.

So funktioniert es

Wer die Schrift in VS Code wechselt, muss normalerweise prüfen, ob sie installiert ist, den genauen Familiennamen ermitteln, settings.json bearbeiten und an die gesonderte Terminaleinstellung denken. CodeFont bündelt diese Schritte in einer Ansicht und trägt die passenden Einstellungen ein.

CodeFont listet eine Schrift erst nach einer tatsächlichen Prüfung auf. Die Angaben in den Metadaten allein genügen nicht:

  • Sie enthält mindestens 76 der 95 druckbaren ASCII-Zeichen.
  • Die Zeichenbreiten von Buchstaben und Ziffern bilden eine einzige Gruppe. Daran lässt sich erkennen, dass Zeichen im Code gleich viel Platz einnehmen.
  • Symbolschriften, Icon-Schriften und Proportionalschriften werden herausgefiltert.

Die Erweiterung liest auch alle Schriftschnitte aus .ttc- und .otc-Sammlungen, folgt symbolischen Verweisen auf Schriftverzeichnisse, speichert Ergebnisse für 24 Stunden zwischen und durchsucht nur geänderte Ordner erneut.

Was CodeFont nicht tut

  • Keine Konten, Telemetrie oder Netzwerkanfragen. Sie müssen sich nicht registrieren. Keine Daten verlassen Ihr Gerät. Der Quellcode ist öffentlich.
  • Kein Herunterladen oder Verkaufen von Schriften. Die Erweiterung arbeitet mit bereits installierten Schriften. Wir erhalten keine Provision.
  • Keine Bearbeitung von Schriften oder Designs. Schriftdateien, Farben und Syntaxhervorhebung bleiben unverändert.
  • Keine Bewertungen oder Erfahrungsberichte. Ob sich die Erweiterung wie beschrieben verhält, können Sie nach der Installation selbst prüfen.
  • Keine versteckten Einstellungen. CodeFont verwendet das Einstellungssystem von VS Code und schreibt die üblichen Schlüssel editor.* und terminal.integrated.*. Ihre späteren Änderungen haben Vorrang.

Wer entwickelt CodeFont?

Ein unabhängiger Entwickler erstellt und pflegt CodeFont. Version 0.1.0 konzentriert sich auf eine eng umrissene Aufgabe und deren zuverlässige Umsetzung.

Voraussetzungen: VS Code ab Version 1.100 unter Windows, macOS oder Linux.
