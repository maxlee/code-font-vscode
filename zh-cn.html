管理 VS Code 编辑器和终端的编程字体

CodeFont 扫描已安装的字体，验证哪些适合写代码，再将你选择的字体应用到编辑器或终端。无需手动编辑 JSON，也不采集遥测数据。

从扩展市场安装浏览字体目录

每款字体都经过验证，才会出现在列表里。

从查找字体到调整排版

CodeFont 会验证本机字体，保存你的收藏，并为编辑器或终端写入相应设置。

验证等宽字体

列出字体前先检查可打印 ASCII 字符的覆盖范围和字符宽度，过滤图标字体、符号字体和非等宽字体。

字体浏览器

在同一列表中查看收藏、已安装和推荐的字体。当前使用的字体旁会显示勾选标记。

编辑器字体设置

在同一面板中设置字体族、字号、字重、行高、字距和备用字体模式，无需编辑 settings.json。

终端字体设置

可以单独配置集成终端，也可以选择继承编辑器字体。设置会写入 terminal.integrated.*。

状态栏与命令

状态栏显示当前字体和字号，点击即可切换字体。也可以从命令面板重新扫描、重置设置或调整字号。

快速本地扫描

读取 .ttc 和 .otc 集合中的全部字体，识别符号链接目录，缓存 24 小时，仅重新扫描有变化的目录。全程在本机运行，不采集遥测数据。

三步开始使用

安装 CodeFont 后，可直接在面板中调整字体设置，无需编辑配置文件。

1

安装 CodeFont

从 VS Code 扩展市场安装。支持 Windows、macOS 和 Linux，需要 VS Code 1.100 或更高版本。

2

打开 CodeFont 面板

点击活动栏中的 CodeFont 图标，字体浏览器会列出收藏、已安装和推荐的字体。

3

应用并调整字体

点击字体即可应用。在编辑器或终端字体设置中调整字号、字重、行高和字距。

CodeFont 0.1.0 的实际表现

这些行为都可以在扩展中亲自验证。

先验证，再列出

在 95 个可打印 ASCII 字符中，字体须至少覆盖 76 个，且字母和数字的字宽须属于同一组。仅在无法测量时才参考元数据。

编辑器和终端可分别设置

更改会写入全局 editor.* 和 terminal.integrated.* 设置。终端可以继承编辑器字体，两者也可以分别重置。

支持字体集合和链接目录

支持 .ttc 和 .otc 集合中的所有字体和通过符号链接访问的目录。缓存保留 24 小时，仅重新扫描有变化的目录。
