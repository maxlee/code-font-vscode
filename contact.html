Each kind of question has a fastest route. Clear reproductions and specific font names move to the front.

Bug reports and feature requests

The fastest route is GitHub Issues. It keeps the conversation public, searchable, and linked to the code that fixes it.

Open GitHub Issues

Include your operating system, VS Code version (Help → About), the font family name, and what you expected versus what happened.

Security issues

Please do not open a public issue for security problems.

Email hi@codefont.dev with a description and, if possible, a reproduction. We will acknowledge within 3 business days.

Because the extension makes zero network requests, any outbound connection is treated as a security issue, not a bug.

Font authors and privacy requests

If you own a font listed in the gallery and want the name, specimen, description, or link corrected — or the listing removed — email hi@codefont.dev with the font name and page URL. We action these within 7 days.

For access, deletion, correction, or any privacy question, email hi@codefont.dev with the subject line “Data request”. We respond within 30 days. See the Privacy Policy.

Everything else

Press, partnerships, or general questions: hi@codefont.dev.
